# حصوني 🕌 — تطبيق متابعة حفظ القرآن الكريم ومراجعته
### (برواية ورش عن نافع)

تطبيق ويب كامل (بدون أي خادم أو قاعدة بيانات) لمتابعة حفظ القرآن الكريم ومراجعته، مبني على نظام **الحصون الخمسة**. يعمل بالكامل داخل المتصفح، ويصلح للنشر مجانًا على **GitHub Pages** لمشاركته مع الطلاب.

---

## 🚀 التشغيل السريع (بدون أي إعداد)

افتح ملف `index.html` مباشرة في أي متصفح (على الحاسوب أو الهاتف). هذا كل ما يلزم — لا حاجة لتثبيت شيء، لا حاجة لـ Node.js أو npm.

---

## 📦 نشره على GitHub Pages (مجانًا) لمشاركته مع الطلاب

### الطريقة الأسهل (بدون سطر أوامر)
1. أنشئ حسابًا على [github.com](https://github.com) إن لم يكن لديك واحد.
2. اضغط **New repository**، اختر اسمًا (مثلًا `husuni`)، اجعله **Public**، ثم **Create repository**.
3. اضغط **uploading an existing file**، ثم اسحب **جميع** محتويات هذا المجلد (وليس المجلد نفسه) وأفلتها، ثم **Commit changes**.
4. من إعدادات المستودع: **Settings → Pages**. تحت **Branch** اختر `main` و `/ (root)` ثم **Save**.
5. بعد دقيقة أو اثنتين، سيظهر رابط بالشكل:
   `https://<اسم-حسابك>.github.io/husuni/`
   شارك هذا الرابط مع طلابك — يعمل من أي متصفح ولا يحتاج أي تنزيل.

### بطريقة سطر الأوامر (git)
```bash
cd husuni-app
git init
git add -A
git commit -m "حصوني: النسخة الأولى"
git branch -M main
git remote add origin https://github.com/<اسم-حسابك>/husuni.git
git push -u origin main
```
ثم فعّل GitHub Pages كما في الخطوة 4 أعلاه.

> 💡 المجلد يحتوي بالفعل على ملف `.gitignore` مناسب، ويمكنك أيضًا تشغيل `git init` بنفسك إن لم يكن موجودًا مسبقًا.

## 📁 هيكل المشروع

```
husuni-app/
├── index.html              الصفحة الرئيسية (نقطة البداية)
├── manifest.json           لدعم «إضافة إلى الشاشة الرئيسية» على الهاتف
├── css/
│   └── styles.css          كل التنسيقات (تصميم فاتح/داكن)
├── data/
│   └── quran-structure.js  بيانات السور/الأجزاء/الأحزاب (مستخرجة آليًا من صفحاتك الحقيقية)
├── js/                     منطق التطبيق (10 ملفات منظمة حسب الوظيفة)
│   ├── quran-helpers.js    دوال مساعدة لهيكل المصحف
│   ├── state.js            التخزين + الحالة + خوارزمية المراجعة
│   ├── shell.js             الأيقونات وهيكل الواجهة
│   ├── view-*.js            كل ملف يمثّل شاشة (الرئيسية، حفظي، المراجعة، التلاوة، المزيد)
│   ├── page-viewer.js       عارض صفحات المصحف
│   └── events-init.js       ربط الأحداث والإقلاع
└── pages/
    └── 1.jpg … 604.jpg      صور صفحات مصحفك الحقيقي (رواية ورش) — 604 صفحة
```

كل شيء ملفات نصية عادية (HTML/CSS/JS) + صور JPG — **لا يوجد أي إطار عمل (framework) ولا خطوة بناء (build step)**، فيمكنك تعديل أي ملف مباشرة بأي محرر نصوص.

## ⚠️ قبل أن تجعل المستودع عامًا: تحقق من حقوق صور المصحف

الصور داخل `pages/` هي نفس صور المصحف الذي رفعتَه (وليست نصًا أعاده الذكاء الاصطناعي كتابةً — لضمان الدقة). لكن **تصميم وطباعة المصحف** (الزخرفة، الخط، التلوين) قد تكون محمية بحقوق نشر خاصة بالجهة التي طبعته، حتى وإن كان نص القرآن نفسه غير خاضع لذلك.

- إن كنت تعرف مصدر هذا المصحف (مجمع ملكي، وزارة أوقاف، دار نشر...) تحقق من إذنهم بإعادة النشر لأغراض تعليمية.
- إن لم تكن متأكدًا: اجعل المستودع **Private** على GitHub بدل Public، وشارك الدعوة مع طلابك مباشرة (Settings → Collaborators)، أو استضف مجلد `pages/` بشكل منفصل (Google Drive مثلًا) واطلب من الطلاب وضعه محليًا.
- الكود نفسه (HTML/CSS/JS) من تأليفي وأتركه لك بترخيص MIT مفتوح تمامًا (انظر `LICENSE`) — لا قيود عليه إطلاقًا.

## ✨ الوظائف المتوفرة
- تصفّح كل السور، مع اختيار وحدة الحفظ: سورة / صفحة / ثمن / ربع / حزب / جزء.
- مساران مستقلّان للحفظ (من البداية ومن النهاية) في الوقت نفسه.
- تصنيف كل صفحة: جديد / ثابت / ضعيف / متفلت — يتحدّث تلقائيًا حسب أداءك.
- «الحصون الخمسة»: حفظ جديد، تثبيت، مراجعة قريبة، مراجعة بعيدة، قراءة مستمرة — تُحسب تلقائيًا كل يوم.
- الخطأ في المراجعة يعيد الصفحة فورًا إلى قائمة التثبيت بجدول مراجعة جديد.
- استماع (اختيار سورة وقارئ برواية ورش، سرعة، تكرار، تكرار مقطع بنقطتي A/B)، اختبار حفظ بلا نص، تسجيل تسميع.
- إحصائيات، ملاحظات ومتشابهات، نسخ احتياطي (تصدير/استيراد JSON)، وضع ليلي، تصميم متجاوب.

## 🔊 ملاحظة عن الصوت

## 💾 حفظ البيانات
بيانات كل مستخدم (حفظه، مراجعاته، تسجيلاته) تُحفظ **محليًا في متصفحه هو فقط** (لا خادم مركزي). كل طالب يفتح الرابط من جهازه سيكون له تقدّمه الخاص المستقل. يُنصح كل طالب بأخذ نسخة احتياطية دوريًا من الإعدادات.
